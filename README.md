# Последний сигнал

Небольшая браузерная 2D-игра в жанре космического хоррора. Игра работает без сборки и зависимостей.

## Запуск

Откройте `index.html` в современном браузере.

## Управление

- `WASD` или стрелки — движение
- Мышь — направление прицела
- Левая кнопка мыши или `Пробел` — стрельба
- `Shift` — рывок
- `Esc` — пауза

## Цель

Соберите 6 биоядер, уничтожая существ, затем доберитесь до маяка в центре сектора.
